## 2026-09-07: YouTube-style drag-to-close on video preview
- Created `useDragToClose.ts` hook using PanResponder + Reanimated
  - Detects vertical-downward drags only (dy > 10, dy > dx * 1.5) to avoid interfering with video player horizontal scrub gestures
  - Provides animated translateY for container, fade opacity for up-next list, and backdrop fade
  - Dismiss threshold: 20% of screen height or velocity > 0.5 px/ms
  - Snaps back with spring animation if threshold not met
- Modified `FilePreviewModal.tsx`:
  - Wrapped outer container with Animated.View + dragContainerStyle (translateY)
  - Added dragPanHandlers to the video player area and the watchInfo section (title, actions, meta chips)
  - Wrapped up-next list in Animated.View with dragUpNextOpacity (fades as user drags)
  - Made modal transparent for video mode to show backdrop fade effect
  - Added dragBackdrop behind content that fades from opaque black to transparent
  - Reset drag state when file prop changes
- Video player controls (play/pause, seek, skip, fullscreen) remain unaffected since:
  - The video player's own PanResponder handles horizontal scrub gestures
  - The drag-to-close only activates on clearly vertical downward movement
  - Video overlay controls (YoutubePlayerOverlay) sit on top with their own pointer events
- **Physics Inertia & Freeze Fix**:
  - Replaced abrupt synchronous `fireClose()` call on release with smooth Reanimated physics inertia spring (`withSpring(SCREEN_HEIGHT + 80, { velocity: Math.max(velocity, 1500), damping: 24, stiffness: 280, mass: 0.5, overshootClamping: true })`).
  - Lowered drag start gesture threshold (`g.dy > 6`) and dismiss threshold (`g.dy > 40 || g.vy > 0.2`) so pulling down slightly carries natural downward momentum and dismisses swiftly without stalling.
  - Added upward flick guard (`g.vy < -0.15`) so changing direction to flick back up restores the video modal smoothly.
  - Added upward drag rubber-band resistance (`g.dy * 0.15`).
  - Invoked `fireClose()` only after the view glides off-screen via `runOnJS`, eliminating freeze/lag during component unmount.
  - Set `animationType={isVideo ? "fade" : "slide"}` on `<Modal>` in `FilePreviewModal.tsx` and added `pointerEvents="none"` to `dragBackdrop`.
